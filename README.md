## 📌 Project Overview

This project focuses on analyzing retail sales data using Python.
The main objective is to understand sales performance, identify
top-performing products, compare different regions, and discover
monthly revenue trends.

## 🎯 Objectives

- Analyze overall retail sales performance.
- Identify the highest revenue-generating categories.
- Find top-performing products.
- Compare region-wise sales.
- Analyze monthly revenue trends.
- Generate meaningful business insights.

## 🛠️ Technologies Used
